Constraints: @constraint

A constraint rejects a copy attempt outright when it does not hold, before the Metropolis test. Each line is a condition in the copy scope (the names of Drives), or one of the built-in rules:

StatementMeaning
connectivity(k₁, k₂, …; rule = Local())the losing cell (of these kinds; all kinds if none) stays locally connected around the target; see Connectivity for the rules (Local(), ArcOrPair(), Simple()) and the soft form in @drive
no_extinctionno copy takes a cell's last site, so cells never disappear
any conditione.g. kind[target] != wall or volume[old] > 5

Conditions follow the rules of drives: rand() and integral are not allowed; keep an integral in a cell variable updated @before_mcs and read it as s[new], s[old] (see Drives).

The connectivity rules read the target's neighbour shell, whatever the model's neighbourhood: the 8 surrounding sites on a square lattice, the 6 on a hexagonal one, the 26 on a cubic 3D one. They, their soft form (@drive connectivity(k; rule, penalty)), the Boolean connected(old; rule) and the shell folds pieces and distinct are described on the Connectivity page, with a mapping from other frameworks.

using Potts

@potts_model Fragile begin
    @structural_parameters begin
        connected = true
    end
    @kinds medium cell
    @lattice Lattice((40, 40); neighborhood = Moore(1))
    @energy begin
        cells(cell) => 0.2 * (volume - 60.0)^2
        contacts => 2.0 * (kind != kind′)
    end
    if connected
        @constraint connectivity(cell)
    end
    @sweep Metropolis(; temperature = 30.0)
end

# number of pieces of cell 1, on 4-neighbour steps
function npieces(σ, c)
    seen = falses(size(σ)); n = 0
    for x in CartesianIndices(σ)
        (σ[x] == c && !seen[x]) || continue
        n += 1; stack = [x]; seen[x] = true
        while !isempty(stack)
            y = pop!(stack)
            for d in (CartesianIndex(1, 0), CartesianIndex(-1, 0), CartesianIndex(0, 1), CartesianIndex(0, -1))
                z = y + d
                checkbounds(Bool, σ, z) && σ[z] == c && !seen[z] && (seen[z] = true; push!(stack, z))
            end
        end
    end
    return n
end

op = layout(Tiling((8, 8); region = (17:24, 17:24), kinds = [:cell]), Fragile(; name = :f))
[npieces(solve(PottsProblem(Fragile(; name = :f, connected = c), op, (0, 100); seed = 1),
              SequentialCPM()).u[end].σ, 1) for c in (true, false)]
2-element Vector{Int64}:
 1
 5

At this high temperature the unconstrained cell breaks into pieces; with connectivity(cell) it stays whole. Connectivity is checked locally around each copy, so it is cheap, and works on the GPU.
