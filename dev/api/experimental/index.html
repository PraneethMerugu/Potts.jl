Experimental API

Experimental surface

These names may change without the stable migration policy. Successful execution does not promote them or establish scientific qualification.

Act

The Act facade remains experimental because design/audits/phase-14-public-api-v2.toml is still wortel-vertical-slice-provisional. Its Persistent Wanderer and Selective Migration Through a Dense Monolayer examples are therefore not part of the required gallery or normal navigation.

Promotion requires an explicit API-registry decision. Documentation will not create stability by showing the examples first.

Experimental algorithms and visualization

  • SequentialEquilibrium requires its own equilibrium evidence.
  • TiledCheckerboardCPM has an experimental scheduler contract and is not a sequential substitute.
  • PottsVolume, PottsExplorer, and RerunController are experimental MakiePotts reference implementations.

ProcessBigraph boundary

Dynamic hierarchy, structural add/remove/divide/move/rewire transactions, and the ProcessBigraphs–Potts adapter are qualified for the unpublished internal beta but remain outside the public Potts workflow until a separate API promotion. Internal qualification is not a public runtime release.

Using experimental names responsibly

Pin the package revision, record the experimental contract identity, isolate usage behind a local adapter, and expect migration work. Do not use an experimental example as evidence for a stable published model or backend claim.

See Capability status for the complete support matrix.

Provisional reference

PottsToolkit

PottsToolkit.Authoring.Act — Type
Act(; maximum_activity, strength, neighborhood, algorithm, observation_every=1)

Level-1 Act-CPM declaration. It lowers completely to the coupled semantic kernel and the ordered CPU/Metal/ROCm realization; it owns no separate runtime or checkpoint semantics.

PottsToolkit.Authoring.FragmentExport — Type

One named immutable public reference of a ModelFragment.

PottsToolkit.Authoring.FragmentPortContract — Type

The semantic contract of one fragment port.

Port contracts are host-side authoring data. They never become runtime storage and are erased after fragment validation and canonical lowering.

PottsToolkit.Authoring.FragmentRequirement — Type

One named typed input contract of a ModelFragment.

PottsToolkit.Authoring.LatticeOwnership — Type
LatticeOwnership(; name=:ownership, namespace=Namespace(:observables))

Typed scientific observable requesting the complete logical ownership lattice and the generation-aware metadata needed to interpret every finite owner.

PottsToolkit.Authoring.ObservedCell — Type

Generation-aware finite-cell metadata accompanying one ownership observation.

PottsToolkit.Authoring.OwnershipValues — Type

Logical ownership values at one observation boundary.

owners is host-owned semantic OwnerRef data. cells supplies generation and biological type for every finite owner, and medium_ids identifies every conceptual medium domain.

PottsToolkit.Authoring.SpatialFrame — Type

One spatial observation captured at Monte Carlo step mcs.

PottsToolkit.Authoring.SpatialSeries — Type

Ordered spatial observations retained by a Potts solution.

The element values remain visualization-neutral. In particular, a SpatialSeries produced by LatticeOwnership contains semantic ownership and cell metadata rather than colors or backend-specific arrays.

PottsToolkit.Authoring.fragment_port_contract — Method

Return the inferred fragment-port contract for a declaration or operation.

Third-party declaration families may extend this host-side protocol to publish richer owner, schema, unit, lifecycle, capability, or backend requirements.

PottsToolkit.Authoring.required_backends — Method

Return the transitive backend requirements of the fully validated authoring graph.

This is a pre-launch requirement set, not a claim that each backend has qualified execution evidence. Runtime preflight remains responsible for rejecting unsupported law/storage/backend tuples before mutation.

CorePotts

CorePotts.ActivityHamiltonian — Type

Activity-dependent Act-CPM Hamiltonian.

The contribution is strength * (activity(recipient) - activity(donor)) / maximum, with activity reduced over each site's same-cell query neighborhood.

CorePotts.ActivityProgram — Type

Complete reusable Act mechanism. semantic_model is authoritative; the remaining fields are compiled CPU-reference realizations of its state and process laws.

CorePotts.AttemptsPerSite — Type

Positive integer source-defined copy-attempt multiplier.

CorePotts.BudgetedSequentialCPM — Type

CPU-reference sequential CPM whose public MCS contains exactly budget.multiplier * N ordered attempts for N mutable recipient sites.

CorePotts.CoupledContractVersions — Type

Inspectable versions for the seven additive coupled semantic-kernel contracts.

CorePotts.LifecycleSpec — Type

Canonical lifecycle transaction policy.

CorePotts.LotteryCPM — Type

Topology-calibrated parallel lottery CPM with equal per-site expected activation.

CorePotts.ObservationSpec — Type

Canonical read-only observation declaration.

CorePotts.PlanEntrySpec — Type

One ordered entry in the exact global execution plan.

CorePotts.PlanSpec — Type

The sole exact time/order authority for a coupled model.

CorePotts.ProcessSpec — Type

One canonical process declaration. The plan supplies cadence and order; this record supplies the law, dependencies, snapshot, and commit boundary.

CorePotts.SemanticModel — Type

The single immutable coupled semantic authority. Runtime state, checkpoints, preflight, and inspection are projections of this value.

CorePotts.SequentialEquilibrium — Type

Metropolis-Hastings sequential sampler for capability-qualified equilibrium models.

CorePotts.SpatialRoles — Type
SpatialRoles(; proposal, contact, surface, connectivity, query, field)

Immutable explicit scientific-role record. Omitted entries retain the frozen lowering for that role. connectivity=nothing is an explicit disable request and is therefore distinct from omission.

CorePotts.StateSpec — Type

One canonical state declaration. Domain-specific state values lower to this record; they do not own independent scheduling, persistence, or fingerprint semantics.

CorePotts.TiledCheckerboardCPM — Type

Deterministic tile-local CPM with explicit snapshot and reconciliation subrounds.

CorePotts.TiledLayout — Type

Host-side immutable description of one topology-derived tile and halo coloring.

CorePotts.TiledReferenceIntegrator — Type

Small host reference whose semantics are independent of optimized backend kernels.

CorePotts.TiledSnapshotAccess — Type
TiledSnapshotAccess(relations=(); dependency_radius=0, cell_wide=false,
                    scratch_words=0, reconciliation=ExactAdditiveTiledReconciliation)

Open, auditable declaration used by TiledCheckerboardCPM. relations names every spatial dependency whose halo must be resident. dependency_radius covers non-relation state dependencies. scratch_words is the bounded per-tile requirement, and reconciliation states whether subround state is an exact additive reduction or a separately qualified bounded-state protocol.

CorePotts.coupled_contract_versions — Method

Return the additive coupled-dynamics contract-version report.

CorePotts.domain_boundaries — Function

Return the logical Cartesian domain boundaries in axis order.

CorePotts.domain_dimensions — Function

Return the logical Cartesian domain dimensions in axis order.

CorePotts.domain_spacing — Function

Return the logical Cartesian lattice spacing in axis order.

CorePotts.problem_geometry — Function

Return the public spatial geometry carried by a Potts problem.

CorePotts.realize_activity — Method

Realize an ActivityProgram against an ownership lattice. All returned execution objects are derived from the program's canonical semantic model.

CorePotts.realize_activity — Method

Realize Act state directly beside an already compiled scientific state.

similar allocation against the compiled ownership tags preserves an existing CPU, Metal, or ROCm backend and the lattice-site cardinality, and therefore performs no adaptation or host-to-device copy.

CorePotts.snapshot_mcs — Function

Return the exact completed-MCS coordinate carried by a saved solution entry.

CorePotts.snapshot_mcs — Method

Return the exact completed-MCS coordinate carried by a saved solution entry.

CorePotts.snapshot_residency — Function

Return the declared storage residency of a saved solution entry.

CorePotts.snapshot_residency — Method

Return the declared storage residency of a saved solution entry.

CorePotts.snapshot_state — Function

Return a complete logical host state retained explicitly by HostSnapshotPolicy.

CorePotts.snapshot_state — Method
snapshot_state(saved::SavedPottsState)

Return the complete logical host state retained by HostSnapshotPolicy.

This accessor never transfers, synchronizes, or reconstructs data. Device, backend-native, and observable-only entries fail with an actionable error.

CorePotts.solution_problem — Function

Return the problem that produced a Potts solution.

MakiePotts

MakiePotts.PottsExplorer — Type

Reference composition of native Makie Blocks. The explorer owns no rendering semantics; its central display is an ordinary PottsPlot.

MakiePotts.PottsVolume — Type

Experimental Makie recipe type for a true three-dimensional frame.

MakiePotts.RerunController — Type

Experimental latest-request-wins rerun coordinator. The runner executes outside Makie recipes and must return a complete value before publication. Call close(controller) to prevent in-flight or future requests from publishing.

MakiePotts.explore_potts — Method
explore_potts(frames; title="Potts model", inspector=true, kwargs...)

Build the experimental reference explorer from already materialized frames. Call close(explorer) to release its slider subscription and optional DataInspector; closing is idempotent.

MakiePotts.pottsvolume! — Function

Add an experimental PottsVolume to an existing Makie scene.

MakiePotts.pottsvolume — Method

Experimental true-three-dimensional volume recipe. Orthogonal slices should use the stable PottsPlot recipe.

MakiePotts.rerun! — Method

Start a nonblocking rerun. Only the latest requested generation may publish. Failures leave the previous complete result intact.

MakiePotts.rerun_error — Function

Return the latest rerun failure Observable, or one containing nothing.

MakiePotts.rerun_result — Function

Return the last completely published result Observable of a RerunController.

MakiePotts.rerun_status — Function

Return the reactive status Observable of a RerunController.
