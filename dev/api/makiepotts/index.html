MakiePotts API

MakiePotts is a native Makie extension over explicit host-owned render frames. It supplies semantic Potts recipes while leaving figure composition, axes, traces, layouts, and export to ordinary Makie.

render every saved staterenderframes
select a 3D planeRenderRequest with OrthogonalSlice

Frame, encode, compose

frames = renderframes(solution)

figure = Figure()
axis = Axis(figure[1, 1]; aspect = DataAspect())
potts_plot = pottsplot!(
    axis,
    last(frames);
    encoding = CellTypeEncoding(),
    boundaries = true,
)
potts_legend(figure[1, 2], potts_plot)

Use ordinary Makie axes beside the spatial panel for volume histories, contact statistics, trajectories, distributions, and uncertainty. The gallery examples demonstrate these compositions and use record_potts for the four temporal mechanisms where motion is part of the lesson.

Understand the boundary

The stable boundary is PottsRenderFrame, not a CorePotts storage object and not a dashboard. Frames carry ownership, generation-aware cell identity, geometry, requested channels, and provenance. Styling remains ordinary Makie attributes.

renderframe never synchronizes a device, transfers backend storage, or reconstructs an undeclared observable. Convert a complete host snapshot or a retained ownership observation before plotting.

For continuous data, request a typed channel and use a ChannelEncoding; the resulting plot works with Makie's standard Colorbar.

Stable API index

MakiePotts.CategoricalEncoding — Constant

The encoding produces semantic categories and a discrete legend.

MakiePotts.CellSite — Constant

A lattice site owned by a finite, generation-aware cell.

MakiePotts.ContinuousEncoding — Constant

The encoding produces numeric values suitable for a Makie Colorbar.

MakiePotts.MediumSite — Constant

A mutable lattice site owned by a medium domain.

MakiePotts.ObstacleSite — Constant

An immutable lattice site owned by a medium domain.

MakiePotts.AbstractChannelRequest — Type

Abstract supertype for open, explicitly materialized channel requests.

MakiePotts.AbstractPottsEncoding — Type

Abstract supertype for semantic frame encodings consumed by Makie recipes.

MakiePotts.AbstractPottsRenderFrame — Type

Abstract supertype for complete Potts render frames with N spatial dimensions. Downstream implementations conform through the exported accessor protocol and render_frame_conformance.

MakiePotts.AbstractRenderChannelScope — Type

Abstract supertype for the scope carried by a typed render-channel key.

MakiePotts.AbstractRenderExtent — Type

Abstract supertype for full-domain and projected render extents.

MakiePotts.CellChannelScope — Type

Marker scope for values keyed by generation-aware finite-cell identity.

MakiePotts.CellIdentity — Type

Generation-aware finite-cell identity.

MakiePotts.CellIdentityEncoding — Type

Encode finite cells by generation-aware identity.

MakiePotts.CellPropertyRequest — Type

Request one finite-cell property by its frozen CorePotts property key.

MakiePotts.CellTypeEncoding — Type

Encode finite cells by biological cell type; this is the default.

MakiePotts.ChannelEncoding — Type

Encode one requested numeric channel.

MakiePotts.EncodedPottsFrame — Type

Numerical array plus semantic mapping produced by an encoding. Styling remains in the recipe and may therefore inherit from Makie themes.

MakiePotts.EncodingKind — Type

Whether an encoding produces categorical or continuous values.

MakiePotts.FullDomain — Type

Request the full two- or three-dimensional ownership domain.

MakiePotts.LegendEntry — Type

One semantic categorical legend entry independent of any Makie Block.

MakiePotts.MediumChannelScope — Type

Marker scope for values keyed by medium-domain identity.

MakiePotts.OrthogonalSlice — Type
OrthogonalSlice(axis, index)

Request a two-dimensional slice by fixing one 3D array axis at index.

MakiePotts.PottsBoundaries — Type

Makie recipe type for a composable finite-cell boundary overlay.

MakiePotts.PottsPlot — Type

Makie recipe type for a two-dimensional frame or orthogonal slice.

MakiePotts.PottsRenderFrame — Type

Canonical, validated render-frame snapshot. Construction defensively copies mutable input containers; callers consume it as logically immutable through the accessor protocol.

MakiePotts.RenderCellMetadata — Type

Semantic metadata for one live finite cell.

MakiePotts.RenderChannel — Type

One explicitly materialized channel. values is an array for site channels, a generation-aware identity-keyed dictionary for cell channels, or a positive medium-domain-ID-keyed dictionary for medium channels.

MakiePotts.RenderChannelKey — Type

A typed semantic key for render data. The scope and value type are part of the key's type, while name provides stable human-readable identity.

MakiePotts.RenderFrameConformance — Type

Reusable downstream conformance result for an open render-frame implementation.

MakiePotts.RenderGeometry — Type

Physical geometry of a rendered ownership array. Coordinates use cell centers; origin is the lower physical edge of the first site.

MakiePotts.RenderOwner — Type

Semantic owner of one rendered lattice site. id is a finite-cell ID for CellSite and a medium-domain ID otherwise.

MakiePotts.RenderOwnerKind — Type

Enumeration describing the semantic owner kind of one lattice site.

MakiePotts.RenderProvenance — Type

Data-lineage record carried by a complete render frame.

MakiePotts.RenderRequest — Type
RenderRequest(; extent=FullDomain(), channels=(), include_cell_metadata=true)

Immutable, visualization-free declaration of the data required by a render frame. Styling belongs to encodings and Makie attributes.

MakiePotts.SiteChannelScope — Type

Marker scope for values defined independently at every lattice site.

Thin recording wrapper over Makie.record. All frames are validated before the first output frame is written.

Lower-level thin wrapper for recording a caller-owned composition. update! receives the current item and must atomically publish its own Observables.
