# [Published Models](@id published-models)

No current page in this manual is classified as a completed published-model reproduction.

`PottsToolkit.ReferenceModels` provides reusable scientific examples and qualification fixtures.
Those constructors are useful implementation building blocks, but a reusable constructor alone
does not establish reproduction fidelity.

The independent
[ProcessBigraphs scientific case-study manual](https://praneethmerugu.github.io/Potts.jl/ProcessBigraphs/dev/case-studies/)
shows complete inline Wortel and Merks assemblies as **qualified
source-bounded case studies**. Those pages deliberately stop below the
published-reproduction class used here.

## Portfolio status

| Class | Admitted | Reader interpretation |
|:--|--:|:--|
| Published reproduction | 0 | No paper-level reproduction claim has passed the admission gate. |
| Partial or failed reproduction | 0 | No archived attempt currently meets the evidence contract for publication here. |
| Literature-inspired example | 0 | The Examples gallery uses concept-level teaching provenance, not paper reproduction claims. |

An entry moves into this table only when its manifest and archived evidence pass independent
scientific review. An empty table is an honest status, not a queue of implied claims.

## Admission requirements

A future published-model page must identify:

- the pinned paper and source revision;
- licensing and provenance for model inputs and assets;
- a machine-readable manifest containing consequential parameters and defaults;
- the exact algorithm, precision, backend, seed policy, replicates, and observation schedule;
- a preregistered figure, table, statistic, or described result;
- mechanistic, execution, parameter, output, and result fidelity classifications;
- archived raw evidence, analysis code, output checksums, and known deviations;
- review status where collaborator review is part of the acceptance contract.

Literature-inspired simplifications remain visibly labeled **Inspired Example**. A failed or partial
reproduction remains visible with its actual result; it is not silently downgraded to an example
after evidence is observed.
